# سیستم طراحی و تم‌بندی رنگی پروژه HikStatus 🎨

**تاریخ تدوین:** ۱۳ مرداد ۱۴۰۵  
**نسخه:** 1.2.0  

این مستند شامل پالت‌های رنگی استاندارد، سیستم طراحی بر پایه متغیرهای CSS (CSS Custom Properties) و راهنمای کامل استفاده از آن در بخش فرانت‌اند پروژه **HikStatus** می‌باشد.

---

## 📐 ساختار سیستم رنگی

سیستم تم‌بندی شامل **۴ استایل متمایز** است که هر کدام دو حالت **روشن (Light)** و **تاریک (Dark)** را پشتیبانی می‌کنند (در مجموع ۸ حالت متغیر):
تمام رنگ‌ها بر اساس قانون **60-30-10** و فرمت **HSL** با رنگ‌های پس‌زمینه ملایم (Saturation زیر ۱۵٪) بازنویسی شده‌اند تا از خستگی چشم در فرآیند مانیتورینگ جلوگیری شود.

0. **Classic Minimal (کلاسیک / ساده و اصلی):** تم ساده، خنثی و بدون اغراق رنگی (کنتراست بالا و غلظت بسیار کم)؛ دقیقا هماهنگ با هویت اولیه سامانه.
1. **Corporate Navy (شرکتی / سرمه‌ای):** استایل رسمی، صنعتی و پایدار؛ مناسب برای داشبوردهای مدیریتی و سازمانی.
2. **Modern Emerald (مدرن / زمردی):** استایل مدرن و تازه‌کننده با تمرکز بر سلامت سیستم‌ها و پایش‌های زنده.
3. **Cyber Violet (سایبر / بنفش):** استایل پیشرفته های‌تک (High-Tech)؛ بسیار جذاب برای مراکز عملیات شبکه (NOC) و مانیتورینگ امنیتی.

## 📊 جدول مقایسه کامل کدهای رنگی (Color Palette Reference Table)

| استایل (Style) | حالت (Mode) | کلید تم (Key) | پس‌زمینه اصلی (`--bg`) | رنگ برند (`--primary`) | رنگ مرز (`--border`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **0. کلاسیک (ساده)** | 🌙 Dark | `classic-dark` | `hsl(240, 5%, 6%)` | `hsl(240, 70%, 65%)` | `hsla(240, 5%, 100%, 0.1)` |
| **0. کلاسیک (ساده)** | ☀️ Light | `classic-light` | `hsl(240, 5%, 98%)` | `hsl(240, 70%, 55%)` | `hsla(240, 5%, 0%, 0.1)` |
| **1. شرکتی (سرمه‌ای)** | 🌙 Dark | `navy-dark` | `hsl(220, 12%, 8%)` | `hsl(210, 80%, 60%)` | `hsla(220, 12%, 100%, 0.1)` |
| **1. شرکتی (سرمه‌ای)** | ☀️ Light | `navy-light` | `hsl(220, 12%, 96%)` | `hsl(220, 60%, 40%)` | `hsla(220, 12%, 0%, 0.1)` |
| **2. مدرن (زمردی)** | 🌙 Dark | `emerald-dark` | `hsl(150, 10%, 8%)` | `hsl(150, 70%, 45%)` | `hsla(150, 10%, 100%, 0.1)` |
| **2. مدرن (زمردی)** | ☀️ Light | `emerald-light` | `hsl(150, 10%, 96%)` | `hsl(150, 70%, 35%)` | `hsla(150, 10%, 0%, 0.1)` |
| **3. سایبر (بنفش)** | 🌙 Dark | `violet-dark` | `hsl(260, 12%, 8%)` | `hsl(270, 70%, 65%)` | `hsla(260, 12%, 100%, 0.1)` |
| **3. سایبر (بنفش)** | ☀️ Light | `violet-light` | `hsl(260, 12%, 96%)` | `hsl(270, 70%, 45%)` | `hsla(260, 12%, 0%, 0.1)` |

> **نکته مهم در مورد رنگ‌های وضعیت (Status Colors):** رنگ‌های وضعیت مانند Success, Danger, Warning, Info کاملاً از تم‌ها ایزوله شده‌اند و در سطح سراسری `:root` با مقادیر ثابت تعریف شده‌اند تا تجربه کاربری همیشه یکپارچه بماند.

## 🎨 متغیرهای جامع CSS (Design Tokens)

```css
/* ==========================================================================
   HikStatus Unified Color System & Design Tokens (HSL)
   ========================================================================== */

/* ===== GLOBAL BASE TOKENS (STATUS COLORS & SETTINGS) ===== */
:root {
    /* Status Colors (Isolated from themes - Muted and accessible) */
    --success: hsl(142, 70%, 45%);
    --success-bg: hsla(142, 70%, 45%, 0.1);
    --danger: hsl(348, 80%, 55%);
    --danger-bg: hsla(348, 80%, 55%, 0.1);
    --warning: hsl(40, 90%, 55%);
    --warning-bg: hsla(40, 90%, 55%, 0.1);
    --info: hsl(210, 90%, 55%);
    --info-bg: hsla(210, 90%, 55%, 0.1);
}

/* --------------------------------------------------------------------------
   0. STYLE 0: CLASSIC MINIMAL (پیش‌فرض سیستم)
   -------------------------------------------------------------------------- */

:root,
[data-theme="classic-dark"] {
    --bg: hsl(240, 5%, 6%);
    --surface: hsl(240, 5%, 10%);
    --border: hsla(240, 5%, 100%, 0.1);
    --primary: hsl(240, 70%, 65%);
    --text: hsl(240, 20%, 96%);
}

[data-theme="classic-light"],
:root[data-theme="light"] {
    --bg: hsl(240, 5%, 98%);
    --surface: hsl(240, 5%, 100%);
    --border: hsla(240, 5%, 0%, 0.1);
    --primary: hsl(240, 70%, 55%);
    --text: hsl(240, 20%, 10%);
}

/* --------------------------------------------------------------------------
   1. STYLE 1: CORPORATE NAVY
   -------------------------------------------------------------------------- */

[data-theme="navy-dark"] {
    --bg: hsl(220, 12%, 8%);
    --surface: hsl(220, 12%, 12%);
    --border: hsla(220, 12%, 100%, 0.1);
    --primary: hsl(210, 80%, 60%);
    --text: hsl(220, 20%, 96%);
}

[data-theme="navy-light"] {
    --bg: hsl(220, 12%, 96%);
    --surface: hsl(220, 12%, 100%);
    --border: hsla(220, 12%, 0%, 0.1);
    --primary: hsl(220, 60%, 40%);
    --text: hsl(220, 20%, 15%);
}

/* --------------------------------------------------------------------------
   2. STYLE 2: MODERN EMERALD
   -------------------------------------------------------------------------- */

[data-theme="emerald-dark"] {
    --bg: hsl(150, 10%, 8%);
    --surface: hsl(150, 10%, 12%);
    --border: hsla(150, 10%, 100%, 0.1);
    --primary: hsl(150, 70%, 45%);
    --text: hsl(150, 20%, 96%);
}

[data-theme="emerald-light"] {
    --bg: hsl(150, 10%, 96%);
    --surface: hsl(150, 10%, 100%);
    --border: hsla(150, 10%, 0%, 0.1);
    --primary: hsl(150, 70%, 35%);
    --text: hsl(150, 20%, 15%);
}

/* --------------------------------------------------------------------------
   3. STYLE 3: CYBER VIOLET
   -------------------------------------------------------------------------- */

[data-theme="violet-dark"] {
    --bg: hsl(260, 12%, 8%);
    --surface: hsl(260, 12%, 12%);
    --border: hsla(260, 12%, 100%, 0.1);
    --primary: hsl(270, 70%, 65%);
    --text: hsl(260, 20%, 96%);
}

[data-theme="violet-light"] {
    --bg: hsl(260, 12%, 96%);
    --surface: hsl(260, 12%, 100%);
    --border: hsla(260, 12%, 0%, 0.1);
    --primary: hsl(270, 70%, 45%);
    --text: hsl(260, 20%, 15%);
}
```
