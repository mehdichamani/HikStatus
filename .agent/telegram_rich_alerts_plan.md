# طرح جامع تجمیع هشدارهای تلگرام و پیاده‌سازی Rich Messages (۲۱ مرداد ۱۴۰۵ - به‌روزرسانی نهایی) 📡

این سند شامل پلان فنی، معماری و ساختار خروجی پیام‌های تلگرام در پروژه **HikStatus** جهت جلوگیری از بمباران پیام، ارتقاء به Rich Messages و تضمین سازگاری عقب‌رو بر پایه **نتایج تست‌های تجربی و عملیاتی** می‌باشد.

> **وضعیت تایید و اعتبارسنجی:** ✅ **تایید نهایی و تست‌شده در محیط عملیاتی (۲۱ مرداد ۱۴۰۵)**  
> ساختار Rich Messages، متد جدید `sendRichMessage` (تا ۳۲,۷۶۸ کاراکتر) و لایه پشتیبان `sendMessage` (با چنکینگ هوشمند زیر ۳۸۰۰ کاراکتر) در تست‌های واقعی تلگرام به اثبات رسید.

## 📌 اهداف اصلی

1. **تجمیع سراسری (Global Aggregation):** ادغام هشدارهای تمام گروه‌های NVR در یک چرخه پایش و ارسال **تنها ۱ پیام جامع** در هر ۵ دقیقه.
2. **ارسال یکپارچه تا ۳۲,۷۶۸ کاراکتر (متد `sendRichMessage`):** بهره‌گیری از متد جدید Telegram Bot API 10.1+ جهت ارسال یکباره پیام‌های بسیار سنگین (تا ۳۲KB) به صورت بلوک‌های ساختاریافته بدون نیاز به شکستن پیام.
3. **لایه پشتیبان هوشمند (Fallback & Smart Chunking):** در صورت استفاده از متد کلاسیک `sendMessage` یا عدم پشتیبانی، فعال‌سازی الگوریتم `split_telegram_message` جهت تفکیک در مرز گروه‌ها و جلوگیری از خطای سقف ۴۰۹۶ کاراکتر (`HTTP 400 Bad Request`).
4. **سازگاری کامل عقب‌رو (Backward Compatibility):** حفظ کارکرد توابع موجود (`send_telegram_raw` و `send_telegram_batch`) و عدم اختلال در فراخوانی‌های تست، هشدارهای تک‌نظارتی و تنظیمات دیتابیس.

## 🎨 فرمت و ساختار خروجی پیام‌های تلگرام

### ۱. ساختار Rich Messages با متد پیشرفته `sendRichMessage` (ارسال یکباره تا ۳۲KB)
در این متد، بدنه پیام به صورت شیءهای ساختاریافته `blocks` شامل انواع `heading` (با اندازه عددی `1` و `2`) و `paragraph` ارسال می‌گردد:

```json
{
  "chat_id": "5659688210",
  "rich_message": {
    "blocks": [
      {
        "type": "heading",
        "text": "🚨 گزارش تجمیعی پایش HikStatus",
        "size": 1
      },
      {
        "type": "paragraph",
        "text": "📅 تاریخ: ۱۴۰۵/۰۵/۲۱ - ساعت ۱۱:۰۰ | 📊 خلاصه وضعیت: ۳۰ گروه درگیر | 🔴 ۱۲۰ دوربین قطع"
      },
      {
        "type": "heading",
        "text": "🏢 گروه: شعبه مرکزی (🔴 ۴ قطعی)",
        "size": 2
      },
      {
        "type": "paragraph",
        "text": "• 🔴 دوربین ورودی اصلی - (192.168.1.50) - قطعی از ۱۰:۰۰\n• 🔴 دوربین پارکینگ - (192.168.1.51) - قطعی از ۱۰:۰۵"
      }
    ]
  }
}
```

### ۲. ساختار Rich HTML با متد متداول `sendMessage` (با چنکینگ هوشمند)
اگر پیام از طریق متد HTML ارسال شود، تگ تاشو `<blockquote expandable>` و تقسیم‌بندی به چنک‌های زیر ۳۸۰۰ کاراکتر اعمال می‌شود:

```html
🚨 <b>گزارش تجمیعی پایش HikStatus</b>
📅 <i>تاریخ: ۱۴۰۵/۰۵/۲۱ - ساعت ۱۱:۰۰</i>
📊 <b>خلاصه وضعیت:</b> ۲ گروه درگیر | 🔴 ۴ دوربین قطع | 🟢 ۱ دوربین وصل مجدد

───────────────────
🏢 <b>گروه: شعبه مرکزی</b> (🔴 ۲ قطعی)
<blockquote expandable>
• 🔴 دوربین ورودی اصلی (<code>192.168.1.50</code>) - قطعی از ۰۹:۴۵
• 🔴 دوربین پارکینگ منفی یک (<code>192.168.1.51</code>) - قطعی از ۰۹:۵۰
</blockquote>
───────────────────
⚙️ <i>سامانه هوشمند پایش تجهیزات HikStatus</i>
```

## 🔄 معماری ترکیبی دو لایه‌ای (Hybrid Dual-Layer Delivery)

سیستم ارسال هشدارهای **HikStatus** بر پایه استراتژی زیر فعالیت خواهد کرد:

1. **لایه اول (Primary):** تلاش برای ارسال گزارش تجمیعی با متد `sendRichMessage`. در این لایه تا **۳۲,۷۶۸ کاراکتر** به صورت یکباره و بدون شکستن پیام تحویل تلگرام می‌شود.
2. **لایه دوم (Fallback):** در صورت بروز هرگونه خطای API یا عدم پشتیبانی، سیستم به صورت خودکار به متد `sendMessage` به همراه تابع `split_telegram_message` سوئیچ می‌کند تا پیام‌ها در چنک‌های متوازن زیر ۳۸۰۰ کاراکتر به همراه تگ تاشو تحویل شوند.

## 🛠️ جزئیات تغییرات کلاسی و ماژول‌ها

### ۱. ماژول `app/services/alerts.py`
* **افزودن تابع `build_aggregated_telegram_message(events_by_group)`**:
  * دریافت هشدارهای تفکیک‌شده و ساخت بدنه پیام.
* **افزودن تابع `split_telegram_message(message, max_chars=3800)`**:
  * محاسبه طول متن و تفکیک هوشمند در مرز گروه‌ها بدون شکستن تگ‌های HTML یا خطوط بدون نیولاین.
* **تطبیق `send_telegram_raw` و `send_telegram_batch`**:
  * پشتیبانی از ارسال ترکیبی (sendRichMessage با Fallback به sendMessage).

### ۲. ماژول `app/services/monitor.py`
* **اصلاح `task_ping_cameras`**:
  * تغییر فراخوانی ارسال هشدار به انتهای چرخه پایش جهت ارسال ۱ پیام جامع تجمیعی برای کلیه گروه‌ها.
