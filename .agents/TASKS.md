# وظایف توسعه پروژه HikStatus

## اولویت بالا
- [x] **تجمیع و کاهش تب‌های پنل وب (UI Consolidation)** - ادغام تب «خلاصه» در «داشبورد» و ادغام تب «درباره ما» در «تنظیمات» جهت بهبود تجربه کاربری و خلوت شدن پنل.
- [ ] **به فایل کاتالوگ امنیتی توی درباره ما لینک بده**
- [ ] **سیستم زمان‌بندی مشابه Jellyfin (Scheduled Tasks)** - ساخت ماژولی مشابه Jellyfin برای نمایش زمان‌بندی‌های دریافت اطلاعات از NVRها، وضعیت کارهای انجام شده/در حال انجام، زمان باقی‌مانده تا اجرای بعدی، امکان متوقف کردن کارها و تغییر فواصل زمانی اجرای تسک‌ها در پنل وب.
- [ ] **داشبورد مدیریتی پیشرفته** - نمایش آمار کلی (تعداد دوربین‌ها، NVRها، قطعی‌ها) با نمودار

- [ ] **سیستم لاگین با OTP/2FA** - امنیت بیشتر برای ورود
- [ ] **پایش پیشرفته وضعیت NVR (NVR Health Monitoring)** - بررسی وضعیت هارد دیسک‌ها (HDD)، دمای دستگاه/فن و وضعیت ضبط کانال‌ها از طریق ISAPI هایک‌ویژن
- [ ] **حالت نگهداری و بی‌صدا کردن موقت (Maintenance Mode & Snooze)** - امکان Snooze کردن دوربین‌های قطع شده و تعریف زمان‌بندی تعمیرات برای توقف موقت مانیتورینگ/اعلان‌ها

## اولویت متوسط
- [ ] **داشبورد عمومی (public)** - صفحه نمایش وضعیت بدون نیاز به لاگین (مثلاً برای تلویزیون)
- [ ] **مرتب‌سازی و جستجوی دوربین‌ها در UI** - جستجوی سریع بین تعداد زیاد دوربین
- [ ] **ذخیره و بروزرسانی دوره ای عکس از دوربین برای تشخیص دوربین در زمان قطعی**
- [ ] **تاریخچه قطعی با نمودار** - نمایش گرافیکی قطعی به جای جدول
- [ ] **تنظیمات پیشرفته ضبط (per-camera)** - قابلیت تنظیم اهمیت و آلرت برای هر دوربین از UI
- [ ] **سیستم برچسب (tag) برای دوربین‌ها** - دسته‌بندی بهتر دوربین‌ها
- [ ] **صفحه نمایش تمام‌صفحه (kiosk mode)** - حالت نمایش برای مانیتورهای بزرگ
- [ ] **قابلیت پیش‌نمایش تصویر زنده (Live Snapshot & Stream)** - گرفتن Snapshot لحظه‌ای و پخش زنده تصویر دوربین‌ها با تبدیل RTSP به WebRTC/HLS در نقشه یا لیست
- [ ] **اعلان پیامکی (SMS Alerts)** - اتصال به پنل‌های پیامکی ایرانی (کاوهنگار، ملی‌پيامک و...) برای ارسال پیامک قطعی دوربین‌های بحرانی (Critical) به مدیران
- [x] **پشتیبانی از چند نقشه (Multi-Map Support)** - امکان آپلود و مدیریت دوربین‌ها روی نقشه‌های مجزا (مانند طبقات و ساختمان‌های مختلف)
- [ ] **ماژولار کردن و تفکیک Endpointها** - تقسیم فایل متمرکز `main.py` به روت‌های مجزا (مانند `auth_routes.py`، `settings_routes.py` و `monitor_routes.py`)
- [ ] **پیاده‌سازی لاگ‌گذاری ساختاریافته (Structured Logging)** - استفاده از کتابخانه‌هایی مانند `structlog` یا `loguru` برای بهبود خوانایی و تحلیل لاگ‌ها

## اولویت پایین
- [ ] **تست‌های اتوماتیک** - pytest برای API و logic
- [ ] **CI/CD pipeline** - GitHub Actions برای تست و دپلوی
- [ ] **داکیومنت API با OpenAPI/Swagger** - فیلد docs_url در FastAPI
- [ ] **نسخه موبایل (PWA)** - تبدیل فرانت‌اند به PWA جهت نصب روی موبایل/دسکتاپ و استفاده شبیه به اپلیکیشن بومی
- [ ] **پشتیبانی از چند زبان** - i18n برای زبان‌های مختلف
- [ ] **Import/Export تنظیمات** - بکاپ JSON از تنظیمات (بدون دیتابیس)
- [ ] **تاریخچه تغییرات کاربران** - audit log برای تغییرات
- [ ] **قابلیت پین کردن دوربین‌ها** - دوربین‌های مهم در بالای لیست
- [ ] **گزارش‌گیری پیشرفته و آمار پایداری (SLA & PDF/Excel)** - محاسبه درصد پایداری (Uptime) دوربین‌ها به صورت هفتگی/ماهانه و خروجی PDF/Excel از لیست قطعی‌ها و داون‌تایم
- [ ] **پشتیبانی از PostgreSQL** - ارائه امکان سوئیچ به PostgreSQL برای محیط‌های بزرگ با حجم لاگ بالا
- [ ] **بهبود مستندات و پیکربندی شبکه داکر** - مستندسازی صریح نیاز به شبکه خارجی `vpn` یا تعریف شبکه پیش‌فرض محلی در `docker-compose.yml`

## بهبود عملکرد
- [ ] **کاهش مصرف حافظه با استریم پاسخ XML** - برای NVRهای با تعداد دوربین زیاد
- [ ] **بهینه‌سازی پرس‌وجوهای دیتابیس** - ایندکس‌گذاری بهتر
- [ ] **Rate limiting برای API** - جلوگیری از سوءاستفاده
- [ ] **استفاده از کتابخانه httpx (Async HTTP)** - جایگزینی requests جهت انجام غیرهمزمان و بهینه‌تر مانیتورینگ NVRها
- [ ] **اصلاح ساختار مدیریت خطاها** - جایگزینی بلاک‌های `except:` کلی با گرفتن استثناهای خاص و لاگ کردن جزئیات خطا

## امنیت
- [ ] **ذخیره توکن در دیتابیس** - session‌ها بعد از ری‌استارت از دست نروند
- [ ] **رمزنگاری پسوردها در دیتابیس** - استفاده از `passlib[bcrypt]` برای پسوردهای دیتابیس و پسورد ادمین در تنظیمات
- [ ] **پیاده‌سازی محافظت در برابر CSRF** - استفاده از توکن‌های CSRF یا انتقال احراز هویت به هدرهای Authorization/JWT
- [ ] **Rate limiting جامع‌تر** - در سطح APIهای حساس
- [ ] **امن‌سازی فرآیند بازیابی بکاپ** - پیاده‌سازی اعتبارسنجی حجم، نوع MIME فایل آپلود شده و جلوگیری از حملات Path Traversal
