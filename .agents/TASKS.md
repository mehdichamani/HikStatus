# وظایف توسعه پروژه HikStatus

## اولویت بالا
- [ ] **داشبورد مدیریتی پیشرفته** - نمایش آمار کلی (تعداد دوربین‌ها، NVRها، قطعی‌ها) با نمودار
- [ ] **سیستم لاگین با OTP/2FA** - امنیت بیشتر برای ورود

## اولویت متوسط
- [ ] **داشبورد عمومی (public)** - صفحه نمایش وضعیت بدون نیاز به لاگین (مثلاً برای تلویزیون)
- [ ] **مرتب‌سازی و جستجوی دوربین‌ها در UI** - جستجوی سریع بین تعداد زیاد دوربین
- [ ] **تاریخچه قطعی با نمودار** - نمایش گرافیکی قطعی به جای جدول
- [ ] **تنظیمات پیشرفته ضبط (per-camera)** - قابلیت تنظیم اهمیت و آلرت برای هر دوربین از UI
- [ ] **سیستم برچسب (tag) برای دوربین‌ها** - دسته‌بندی بهتر دوربین‌ها
- [ ] **صفحه نمایش تمام‌صفحه (kiosk mode)** - حالت نمایش برای مانیتورهای بزرگ

## اولویت پایین
- [ ] **تست‌های اتوماتیک** - pytest برای API و logic
- [ ] **CI/CD pipeline** - GitHub Actions برای تست و دپلوی
- [ ] **داکیومنت API با OpenAPI/Swagger** - فیلد docs_url در FastAPI
- [ ] **نسخه موبایل (PWA)** - قابلیت نصب روی گوشی
- [ ] **پشتیبانی از چند زبان** - i18n برای زبان‌های مختلف
- [ ] **Import/Export تنظیمات** - بکاپ JSON از تنظیمات (بدون دیتابیس)
- [ ] **تاریخچه تغییرات کاربران** - audit log برای تغییرات
- [ ] **قابلیت پین کردن دوربین‌ها** - دوربین‌های مهم در بالای لیست

## بهبود عملکرد
- [ ] **کاهش مصرف حافظه با استریم پاسخ XML** - برای NVRهای با تعداد دوربین زیاد
- [ ] **بهینه‌سازی پرس‌وجوهای دیتابیس** - ایندکس‌گذاری بهتر
- [ ] **Rate limiting برای API** - جلوگیری از سوءاستفاده

## امنیت
- [ ] **ذخیره توکن در دیتابیس** - session‌ها بعد از ری‌استارت از دست نروند
- [ ] **رمزنگاری پسوردها در دیتابیس** - hash قوی‌تر با salt (الان sha256 ساده)
- [ ] **CSRF protection**
- [ ] **Rate limiting جامع‌تر** - در سطح APIهای حساس
