🔑 راهنمای تغییر رمز عبور مدیر سیستم (Admin)

به دلایل امنیتی، اطلاعات ورود حساب مدیر سیستم در دیتابیس ذخیره نمی‌شود و تغییر آن مستقیماً از طریق فایل پیکربندی سرور (تنظیمات محیطی) انجام می‌گردد.

نکته مهم: دستور docker compose restart مقادیر جدید فایل .env را اعمال نمی‌کند؛ زیرا متغیرهای محیطی هنگام ساخت و ایجاد کانتینر ارزیابی می‌شوند. برای اعمال تغییرات حتماً باید کانتینر را مجدداً ایجاد (Recreate) کنید.
مراحل تغییر رمز در محیط داکر:
  1. فایل تنظیمات محیطی پروژه به نام .env را در سرور باز کنید.
  2. برای افزایش امنیت، پیشنهاد می‌کنیم از رمز عبور هش‌شده استفاده کنید. جهت تولید هش کلمه عبور جدید، دستور زیر را در سرور اجرا کنید: 
    docker exec -it hikstatus python -c "import database; print(database.hash_password('your_new_password'))"
    (عبارت your_new_password را با رمز دلخواه خود جایگزین کنید).
  3. خروجی تولید شده (مانند e4f9b8c0...:d1a2f3...) را کپی کرده و در فایل .env مقابل متغیر ADMIN_PASS قرار دهید: 
    ADMIN_USER=admin
ADMIN_PASS=مقدار_هش_کپی_شده
    (همچنین می‌توانید رمز عبور را به صورت خام و ساده نیز مقابل متغیر قرار دهید، اما از نظر امنیتی توصیه نمی‌شود).
  4. با دستور زیر، کانتینر را مجدداً ایجاد و راه‌اندازی کنید تا متغیرها اعمال شوند: 
    docker compose down && docker compose up -d
مراحل تغییر رمز در اجرای مستقیم پایتون:
  1. فایل تنظیمات محیطی پروژه به نام .env را باز کنید.
  2. جهت تولید هش رمز عبور (توصیه شده از نظر امنیتی)، دستور زیر را در خط فرمان سیستم خود اجرا کنید: 
    python -c "import hashlib, secrets; salt = secrets.token_bytes(16); hash_bytes = hashlib.pbkdf2_hmac('sha256', b'your_new_password', salt, 100000); print(f'{salt.hex()}:{hash_bytes.hex()}')"
  3. خروجی تولید شده را در فایل .env قرار دهید: 
    ADMIN_USER=admin
ADMIN_PASS=مقدار_هش_تولید_شده
  4. سرویس یا پروسس پایتون برنامه را مجدداً راه‌اندازی (Restart) کنید تا فایل تنظیمات .env مجدداً خوانده شود.
