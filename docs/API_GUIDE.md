# راهنمای پایانه‌های وب‌سرویس (API Guide) 🔌

سامانه **HikStatus** یک واسط وب‌سرویس RESTful مبتنی بر **FastAPI** ارائه می‌دهد که تمامی عملکردهای مانیتورینگ، کنترل تجهیزات، مدیریت سشن‌ها و گزارش‌گیری‌ها را مدیریت می‌کند. در این مستند، پرکاربردترین اندپوئینت‌های سامانه به تفکیک نقش‌های دسترسی تبیین شده‌اند.

---

## 🔑 ۱. سیستم احراز هویت و نشست‌ها (Authentication & Session)

| متد | پایانه API | سطح دسترسی | توضیحات عملکرد |
| :---: | :--- | :---: | :--- |
| `POST` | `/api/auth/login` | عمومی | ورود به سیستم با ارسال نام‌کاربری، رمزعبور و کد دو مرحله‌ای (در صورت فعال بودن). سشن ایجاد شده در کوکی ذخیره می‌شود. |
| `POST` | `/api/auth/logout` | عمومی | خروج از سیستم و ابطال توکن سشن جاری در پایگاه داده. |
| `GET` | `/api/auth/me` | عمومی | دریافت اطلاعات نمایه کاربر فعلی شامل نقش، نام‌کاربری و دسترسی کارخانجات. |
| `POST` | `/api/me/change-password` | عمومی | تغییر رمز عبور کاربر جاری؛ این کار باعث ابطال تمام نشست‌های فعال کاربر می‌شود. |
| `POST` | `/api/me/two-factor/setup` | عمومی | فعال‌سازی احراز هویت دو مرحله‌ای (2FA) و دریافت کد سکرت به همراه QR Code تصویری. |
| `POST` | `/api/me/two-factor/verify` | عمومی | تایید نهایی کدهای OTP صادر شده جهت فعال‌سازی دائمی حالت دو مرحله‌ای. |

## 📽️ ۲. مدیریت دستگاه‌های ضبط و دوربین‌ها (NVR & Camera Management)

| متد | پایانه API | سطح دسترسی | توضیحات عملکرد |
| :---: | :--- | :---: | :--- |
| `GET` | `/api/nvrs` | مانیتور | لیست کردن تمامی دستگاه‌های NVR به همراه آخرین وضعیت ارتباطی و خطاهای آن‌ها. |
| `POST` | `/api/nvrs` | مدیر سیستم | افزودن NVR جدید به سیستم (نام، آی‌پی، نام کاربری و پسوردی که با الگوریتم Fernet رمزگذاری می‌شود). |
| `PUT` | `/api/nvrs/{ip}` | مدیر سیستم | ویرایش اطلاعات اتصال یا نام یک NVR. تغییر آی‌پی باعث انتقال اتمیک داده‌های دوربین‌های زیرمجموعه می‌شود. |
| `DELETE` | `/api/nvrs/{ip}` | مدیر سیستم | حذف دستگاه NVR به همراه حذف آبشاری (Cascade) دوربین‌ها و رویدادهای قطعی مربوطه. |
| `GET` | `/api/cameras` | مانیتور | دریافت لیست کامل دوربین‌ها فیلتر شده بر اساس گروه‌های مجاز کاربر جاری. |
| `PUT` | `/api/cameras/{id}` | مدیر IT | ویرایش مشخصات دوربین شامل نام، سطح اهمیت (Low/Normal/Critical)، فیلد بی‌صدا (Mute) و زاویه مخروط دید (FOV). |
| `GET` | `/api/cameras/{id}/snapshot` | مانیتور | واکشی مستقیم تصویر زنده از دوربین مربوطه از طریق وب‌سرویس NVR با فرمت JPEG. |
| `GET` | `/api/cameras/{id}/stream` | مانیتور | پروکسی و پخش جریانی ویدئویی زنده دوربین (RTSP به JPEG متحرک). دارای محدودیت سقف تعداد اتصال همزمان. |

## 🛠️ ۳. مدیریت گروه‌ها و کاربران (Groups & RBAC Users)

| متد | پایانه API | سطح دسترسی | توضیحات عملکرد |
| :---: | :--- | :---: | :--- |
| `GET` | `/api/groups` | مانیتور | مشاهده گروه‌های کاربری فعال (کارخانجات) و موقعیت پیش‌فرض نقشه‌ها. |
| `POST` | `/api/groups` | مدیر سیستم | ایجاد گروه جدید برای تفکیک دستگاه‌ها و دوربین‌ها. |
| `GET` | `/api/users` | مدیر سیستم | لیست کامل کاربران به همراه نقش‌ها، وضعیت فعال بودن و گروه‌های دسترسی چندگانه. |
| `POST` | `/api/users` | مدیر سیستم | ثبت نام کاربر جدید با تخصیص نقش کاربری و اعتبارسنجی گروه‌های چندگانه مجاز. |
| `PUT` | `/api/users/{id}` | مدیر سیستم | ویرایش اطلاعات حساب کاربری، سلب دسترسی‌ها، تغییر نقش یا فعال/غیرفعال‌سازی وضعیت حساب. |
| `PUT` | `/api/me/alerts` | مانیتور | به‌روزرسانی اطلاعات نوتیفیکیشن‌های ایمیل یا چت‌آیدی تلگرام کاربر فعلی (محدود به حداکثر یک مقدار). |

## 📑 ۴. رفع ابهام قطعی‌ها و گزارش‌ها (Outages & Reports)

| متد | پایانه API | سطح دسترسی | توضیحات عملکرد |
| :---: | :--- | :---: | :--- |
| `GET` | `/api/outage-explanations` | مانیتور | لیست قطعی‌های نیازمند توضیح بر اساس فیلترهای صفحه‌بندی (۱۵ آیتم در صفحه) و فیلترهای جستجوی زنده نام دوربین. |
| `POST` | `/api/outage-explanations/bulk` | مدیر IT / ناظر | ثبت توضیح و علت قطعی به صورت فله‌ای (Bulk) برای چندین دوربین با انتخاب دسته‌جمعی. |
| `PUT` | `/api/outage-explanations/{id}` | مدیر IT / ناظر | ثبت توضیح علت قطعی برای یک رکورد خاص پیش از سررسید مهلت ثبت (Deadline). ادمین محدودیت زمانی ندارد. |
| `GET` | `/api/outage-causes` | مانیتور | دریافت علت‌های استاندارد و فعال قطعی دوربین‌ها جهت استفاده در فرم رفع ابهام. |
| `GET` | `/api/reports/generate` | مانیتور | تولید خروجی گزارش پایداری شبکه دوربین‌ها بدون گلوگاه عملکردی با فرمت متنی یا اکسل. |
| `GET` | `/api/logs` | مانیتور | جستجو، فیلتر و واکشی لاگ‌های مانیتورینگ و لاگ‌های امنیتی (Audit Logs) سیستم. |

## 🔒 ۵. مدیریت داده‌ها و کارهای زمان‌بندی‌شده (Data & Tasks)

| متد | پایانه API | سطح دسترسی | توضیحات عملکرد |
| :---: | :--- | :---: | :--- |
| `GET` | `/api/scheduler/tasks` | مدیر سیستم | مشاهده وظایف فعال پس‌زمینه به همراه تاریخچه زمان اجرا، مدت زمان طول کشیدن و آخرین خطاها. |
| `POST` | `/api/scheduler/tasks/{task_id}/run` | مدیر سیستم | اجرای دستی کارهای زمان‌بندی شده خارج از نوبت (مثلاً اسکن سلامت NVRها یا بازسازی آمارها). |
| `GET` | `/api/data/backup` | مدیر سیستم | دانلود مستقیم کل پایگاه داده `monitor.db` به صورت فایل آفلاین. |
| `POST` | `/api/data/restore` | مدیر سیستم | آپلود و بازگردانی دیتابیس از فایل پشتیبان با اعتبارسنجی هدرهای هگزادسیمال SQLite. |
| `POST` | `/api/data/purge/empty` | مدیر سیستم | پاکسازی کامل دیتابیس و بازگردانی تنظیمات به وضعیت کارخانه (سیستم خالی). |
| `POST` | `/api/data/purge/init` | مدیر سیستم | پاکسازی کامل دیتابیس و لود مجدد اطلاعات از روی فایل پیکربندی پیش‌فرض `init_config.json`. |

## 📌 راهنمای کدهای وضعیت پاسخ (Response Status Codes)

* **`200 OK`:** فرآیند با موفقیت انجام شد و داده‌های درخواستی بازگردانده شدند.
* **`400 Bad Request`:** خطای منطقی یا عدم اعتبارسنجی داده‌های ورودی (مثلاً فرمت اشتباه ایمیل یا ثبت علت تکراری).
* **`401 Unauthorized`:** نشست کاربری شما معتبر نیست یا منقضی شده است (باید ابتدا وارد شوید).
* **`403 Forbidden`:** سطح دسترسی نقش شما برای فراخوانی این API کافی نیست.
* **`404 Not Found`:** رکورد درخواستی (دوربین، NVR یا کاربر) در سیستم پیدا نشد.
* **`429 Too Many Requests`:** تعداد درخواست‌های شما از نرخ مجاز Rate Limiter فراتر رفته است.
* **`500 Internal Server Error`:** خطای سیستمی بک‌اند در زمان اجرا یا عدم توانایی اتصال به پایگاه داده.
