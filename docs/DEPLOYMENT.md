# راهنمای نصب، راه‌اندازی و استقرار HikStatus 🐳

این راهنما، فرآیند گام‌به‌گام راه‌اندازی و استقرار سامانه مانیتورینگ **HikStatus** را در محیط‌های مختلف (داکر، لینوکس بومی و ویندوز) تشریح می‌کند. همچنین جزئیات مربوط به تنظیمات امنیتی دستگاه‌های هایک‌ویژن در انتهای مستند آورده شده است.

---

## 🛠️ ۱. پیش‌نیازهای نرم‌افزاری

پیش از شروع فرآیند نصب، مطمئن شوید ابزارهای زیر بر روی سیستم شما نصب هستند:
* **روش داکر:** Docker Engine نسخه ۲۰.۱۰ به بالا و Docker Compose نسخه ۲.۰ به بالا.
* **روش بومی (Native):** پایتون نسخه ۳.۱۰ یا بالاتر به همراه ابزار مدیریت بسته `pip`.

---

## 📦 ۲. استقرار با داکر (Docker - روش توصیه‌شده)

استفاده از داکر بهترین و پایدارترین راهکار برای اجرای پروژه در محیط‌های پروداکشن است؛ چرا که تمامی وابستگی‌ها و بسته‌های سیستمی از پیش در کانتینر تنظیم شده‌اند.

### گام اول: کپی تنظیمات متغیرهای محیطی
ابتدا فایل نمونه تنظیمات محیطی را کپی و ویرایش کنید:
```bash
cp .env.example .env
```
فایل `.env` را باز کرده و مقادیر نام کاربری و پسورد پیش‌فرض مدیریت را تنظیم نمایید:
```env
ADMIN_USER=admin
ADMIN_PASS=your-secure-password
```

### گام دوم: ایجاد تنظیمات اولیه NVRها (اختیاری)
اگر می‌خواهید در اولین اجرای برنامه، لیست دستگاه‌های ضبط و تنظیمات سیستم به طور خودکار مقداردهی اولیه شوند، فایل زیر را تنظیم کنید:
```bash
cp init_config.example.json init_config.json
```
اطلاعات NVRها و پورت‌ها را مطابق با اطلاعات شبکه خود ویرایش کنید.

### گام سوم: ساخت و اجرای کانتینر
دستور زیر را برای بیلد ایمیج و اجرای برنامه در پس‌زمینه وارد نمایید:
```bash
docker compose up -d
```

> [!IMPORTANT]
> **شبکه خارجی داکر (`vpn`)**
>
> فایل پیش‌فرض `docker-compose.yml` به یک شبکه خارجی به نام `vpn` متصل است.
> - اگر از این شبکه اختصاصی استفاده می‌کنید، ابتدا آن را ایجاد کنید:
>   ```bash
>   docker network create vpn
>   ```
> - در غیر این صورت، بخش `networks` را در انتهای فایل داکر کامپوز کامنت یا حذف کنید تا کانتینر از شبکه پیش‌فرض پل (Bridge) داکر استفاده نماید.

## 🐍 ۳. راه‌اندازی بومی (روی لینوکس و مک)

در صورتی که می‌خواهید پروژه را مستقیماً روی سرور لینوکسی بدون لایه مجازی‌ساز اجرا کنید، مراحل زیر را طی نمایید:

1. فایل `.env` و `init_config.json` را مشابه بخش داکر تنظیم کنید.
2. اسکریپت راه‌انداز پروژه را اجرایی کرده و آن را اجرا کنید:
```bash
chmod +x start.sh
./start.sh
```
این اسکریپت به طور خودکار یک محیط مجازی پایتون (`.venv`) ایجاد کرده، تمامی پیش‌نیازها را از فایل `requirements.txt` نصب می‌کند و سرور وب را اجرا می‌نماید.

برای اجرا روی پورت دلخواه (مثلاً ۸۰۸۰):
```bash
./start.sh 8080
```

---

## 🪟 ۴. راه‌اندازی بومی (روی سیستم‌عامل ویندوز)

جهت استقرار بر روی سرورهای ویندوز، مراحل زیر را دنبال کنید:

1. نسخه پایتون ۳.۱۰ یا بالاتر را نصب کرده و مطمئن شوید گزینه **"Add Python to PATH"** را فعال کرده‌اید.
2. فایل `.env` و `init_config.json` را مطابق نیاز کپی و تنظیم کنید.
3. ترمینال CMD را باز کرده و برای نصب اولیه وابستگی‌ها دستور زیر را بزنید:
```cmd
install.bat
```
4. پس از اتمام نصب، برای اجرای وب‌سرور دستور زیر را اجرا کنید:
```cmd
start.bat
```

## 🌐 ۵. دسترسی به پنل کاربری

پس از بالا آمدن موفقیت‌آمیز سرور وب، مرورگر خود را باز کرده و به آدرس زیر بروید:
* **آدرس پنل:** `http://localhost:28888`
* **اطلاعات ورود اولیه:** نام کاربری و پسوردی که در فایل `.env` مشخص نموده‌اید (در صورت عدم تنظیم، به طور پیش‌فرض `admin` / `admin` خواهد بود).

## 🔒 ۶. تنظیمات احراز هویت دستگاه‌های HikVision

بسیاری از تجهیزات هایک‌ویژن به دلیل سیاست‌های امنیتی، درخواست‌های وب‌سرویس پایش را مسدود می‌کنند مگر اینکه قابلیت **ISAPI** و احراز هویت نوع **Digest** فعال باشند. در صورت بروز خطای `401 Unauthorized` یا آفلاین ماندن فرضی دوربین‌ها، راهنمای زیر را بر روی پنل وب NVR اعمال کنید:

### فعال‌سازی پروتکل ارتباطی ISAPI
1. به پنل مدیریت وب NVR هایک‌ویژن خود لاگین کنید.
2. به مسیر زیر مراجعه کنید:
   ```text
   Configuration → Network → Advanced Settings → Integration Protocol
   ```
   *(در برخی نسخه‌ها: `Configuration → System → Security`)*
3. گزینه **Enable Hikvision-CGI** یا **Enable ISAPI** را پیدا کرده و تیک فعال‌سازی آن را بزنید.

### تنظیم نوع احراز هویت
1. در همان صفحه تنظیمات امنیتی، حالت احراز هویت وب‌سرویس (CGI/ISAPI Authentication) را بر روی وضعیت **digest/basic** یا **Digest** قرار دهید.
2. از قرار دادن آن روی حالت `basic only` به دلیل خطرات امنیتی و همچنین ممانعت از کارکرد صحیح مانیتورینگ بپرهیزید.
3. تنظیمات را ذخیره کرده و در صورت نیاز یک‌بار NVR را راه‌اندازی مجدد کنید.

### ساخت کاربر مجزا و کم‌دسترسی برای HikStatus (بهترین اقدام امنیتی)
به جای استفاده از رمز عبور ادمین اصلی دستگاه ضبط تصاویر در سامانه، یک کاربر مانیتور اختصاصی ایجاد کنید:
1. به مسیر `Configuration → System → User Management` بروید.
2. دکمه افزودن کاربر جدید را بزنید و یک حساب بسازید (به عنوان مثال نام کاربری: `hikstatus`).
3. در تب دسترسی‌ها (Permissions)، تنها دسترسی‌های خواندن و پیش‌نمایش را تیک بزنید:
   * **Remote Configuration** (جهت همگام‌سازی نام کانال‌ها)
   * **Remote Live View** یا **Preview** (جهت گرفتن عکس لحظه‌ای و استریم زنده)
   * **Device Management / View Status** (جهت واکشی وضعیت هاردها و منابع سخت‌افزاری)
4. تغییرات را ذخیره کرده و اطلاعات این کاربر جدید را در بخش تنظیمات NVRهای سامانه وارد کنید.
